🍓 ラズパイプログラミング

Pythonコード共有サイト - コピーして実行してみよう！

🛠️ はじめに：ラズパイの準備Pi 5 / Pi 4 対応

このサイトのコードは Raspberry Pi 5 / Pi 4 と最新の Raspberry Pi OS(Bookworm・Trixie)で動くように作っています。

① GPIO(LED・ボタン・サーボ・超音波センサー)のコード

準備は不要です。使っている gpiozero は Raspberry Pi OS に最初から入っています。python3 ファイル名.py で実行できます。

もし ModuleNotFoundError: No module named 'gpiozero' と出たら、次を実行してください。

sudo apt update
sudo apt install -y python3-gpiozero python3-lgpio

② 温湿度センサー(DHT22)を使うコード ※最初に1回だけ

DHT22用のライブラリはOSに入っていないので、仮想環境(venv)を作ってその中にインストールします。上から順に1行ずつ実行してください。

# 1. 必要なパッケージ
sudo apt update
sudo apt install -y python3-venv python3-full python3-lgpio

# 2. 仮想環境を作成(OSのGPIOライブラリも使えるようにする)
python3 -m venv --system-site-packages ~/rasp-env

# 3. 仮想環境に入る(行頭に (rasp-env) と表示されればOK)
source ~/rasp-env/bin/activate

# 4. ライブラリをインストール
pip install adafruit-circuitpython-dht

2回目以降は、ターミナルを開くたびに source ~/rasp-env/bin/activate を実行してから python ファイル名.py で実行します。

③ うまくいかないとき

エラー・症状原因と対処
error: externally-managed-environment新しいOSではシステムに直接 pip install できません。②の手順で仮想環境を作り、(rasp-env) と表示された状態で pip install してください。
※ --break-system-packages はOSを壊すおそれがあるので使わないでください。
Unable to locate package libgpiod2Trixie(Debian 13)ではパッケージ名が変わりました。②の手順のパッケージだけで動くので、libgpiod2 は不要です。
pip3 install Adafruit_DHT が失敗する / Unknown platformAdafruit_DHT は開発終了したライブラリで、Pi 5では動きません。このサイトのDHT22のコード(adafruit_dht 版)を使ってください。
import RPi.GPIO で Cannot determine SOC peripheral base address などのエラーRPi.GPIO は Pi 5 では動きません。このサイトのコード(gpiozero 版)を使ってください。
No module named 'adafruit_dht' / 'board' / 'RPLCD'仮想環境に入っていません。source ~/rasp-env/bin/activate を実行してからもう一度実行してください。
GPIO busy / pin is already in use前に実行したプログラムがまだ動いています。Ctrl+C で止めるか、ターミナルを開き直してください。
DHT22で「読み取り失敗」がときどき出るDHT22ではよくあることです。数値が表示される回があれば正常です。ずっと失敗する場合は配線(DATAのピン番号・10kΩプルアップ)を確認してください。

機種の確認: cat /proc/device-tree/model ／ OSの確認: grep VERSION= /etc/os-release
