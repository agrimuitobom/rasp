このページのコードは MicroPython(マイコン用のPython)で書いています。Raspberry Pi の Python とは書き方が少しちがうので、Raspberry Pi 用のページのコードはそのままでは動きません。

① Thonny を用意する

  • Raspberry Pi で使う場合: メニュー →「プログラミング」→「Thonny」。最初から入っています。
  • Windows / Mac で使う場合: thonny.org からダウンロードしてインストールします。

② Pico に MicroPython を入れる ※最初に1回だけ

  • Pico の BOOTSEL ボタンを押したまま USBケーブルでパソコンにつなぎ、つないだらボタンをはなします。
  • Thonny の右下(「Python 3...」と書かれた部分)をクリック →「MicroPythonをインストールまたは更新」を選びます。
  • 「variant」で自分の Pico(Raspberry Pi Pico / Pico W / Pico 2 など)を選んで「インストール」を押します。
  • うまくいかないときは、micropython.org から自分の機種の .uf2 ファイルをダウンロードし、BOOTSELモードで表示される RPI-RP2(Pico 2 は RP2350)ドライブにドラッグしても入れられます。

③ Thonny と Pico をつなぐ

  • BOOTSEL を押さずに USB でつなぎ、Thonny の右下をクリック →「MicroPython (Raspberry Pi Pico)」を選びます。
  • 下の「シェル」に >>> と出れば接続できています。
  • このページのコードをコピーして Thonny に貼り付け、▶「実行」(F5)で動きます。止めるときは ■「停止」です。
  • パソコンから抜いても(電池やUSB充電器で)動かしたいときは、「名前を付けて保存」→「Raspberry Pi Pico」→ main.py という名前で保存します。電源が入ると自動で動きます。

④ ピン番号の見かた

コードの Pin(15) は GP15 のことで、基板の端から数えた「20番ピン」とは別の番号です。基板の裏面に GP15 などと印刷されているので、それを見て配線しましょう。このページでは配線に「GP15(20番ピン)」のように両方を書いています。

名前ピン番号使いみち
3V3(OUT)36番センサーの電源(3.3V)
GND3, 8, 13, 18, 23, 28, 33, 38番マイナス(どれを使ってもOK)
GP1520番LED・DHT22 の DATA
GP26 / ADC031番土壌水分センサーなどアナログ値の読み取り

⑤ うまくいかないとき

エラー・症状原因と対処
Thonny で Pico が見つからない / Couldn't find the deviceUSBケーブルが「充電専用」の可能性があります。データ通信できるケーブルに変えてください。MicroPython が入っていない場合は②をやり直します。
ImportError: no module named 'machine'パソコンのPythonで実行しています。Thonny の右下で「MicroPython (Raspberry Pi Pico)」を選んでください。
ImportError: no module named 'gpiozero' / 'RPi'Raspberry Pi 用のコードです。Pico では machine モジュールを使うこのページのコードを使ってください。
Device is busy / 実行できないPico で前のプログラム(main.py など)が動いています。Thonny の ■「停止」を押してから実行してください。
DHT22で OSError: [Errno 110] ETIMEDOUTセンサーから返事がありません。DATAのピン番号(GP15 = 20番ピン)、電源の向き、10kΩ の抵抗を確認してください。ときどき出るだけなら正常です。
土壌水分の値がずっと 0 や 65535 付近のままAOUT が GP26(31番ピン)につながっているか確認してください。センサーの電源は 3V3 につなぎます。
